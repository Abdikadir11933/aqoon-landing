# Working-artifact context

`working/` is disposable space for audits, extraction notes, migration tables, comparison drafts and research scratch work.

Nothing here is automatically current or safe to publish.

Every working artifact should state:

- purpose
- created/checked date
- inputs/sources
- status
- intended canonical destination

Delete or archive obsolete working artifacts only when their useful conclusions have been reconciled into canonical homes.

Never store secrets, family PII, tracker passwords, private messages or confidential partner/customer material here. The repository is public.
