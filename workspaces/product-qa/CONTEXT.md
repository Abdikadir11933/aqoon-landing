# Product QA Context

Run independent passes rather than one blended check:
1. structure/routing/data-boundary QA
2. source/fact-integrity QA
3. route/advice/safety + language/terminology QA

For UI changes also apply `BRAND.md` and existing automated site tests. `pilke/` is protected.

For a homepage or buyer-journey critique, follow `.claude/skills/website-review/SKILL.md`: inspect the actual mobile and desktop experience and deliver a prioritized, concrete rewrite/implementation brief. For instruction and folder architecture, use `.claude/skills/repository-auditing/SKILL.md` in context-only mode.
