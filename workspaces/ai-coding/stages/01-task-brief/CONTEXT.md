# Stage 01 — task brief

## Inputs

The user request, current repository router and any explicit exclusions.

## Process

Rewrite the request as one observable outcome. Record scope, non-goals,
protected areas, risk level and whether production data or deployment is
involved. Do not expand “update” into an unrelated redesign.

## Outputs

A short brief containing Outcome, In scope, Out of scope, Constraints and
Acceptance checks.
