# Family research loop

1. Keep the family-specific interview in protected private systems.
2. Derive only the non-identifying scenario dimensions that materially affect routing.
3. Search the reusable scenario store before doing new deep research.
4. If an exact verified scenario is current, reuse it and verify only case-specific unknowns.
5. If the scenario is stale, use it as a hypothesis and recheck volatile facts.
6. If it is new, research the smallest set of unknowns needed to choose the next 1–3 routes.
7. Prefer current primary sources from the responsible authority/provider.
8. Separate clearly:
   - known family facts
   - verified published criteria/process
   - AQOON explanation/navigation
   - unknowns that need confirmation
   - final decisions only an authority/provider/employer can make
9. Save back only generalized, PII-free reusable knowledge: verified answer, conditions, next steps, official sources, operator guidance and a recheck date.
10. Never copy family names, phones, exact addresses, private free text or unnecessary personal narrative into reusable scenario knowledge.

A scenario match is a routing aid, not a promise of eligibility or outcome.
