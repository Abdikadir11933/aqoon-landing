# Finland navigation coverage register — 28 August 2026

## Current truth

AQOON does **not** yet understand every Kela benefit, public service, municipal rule, project or programme. The repository has a small verified route seed and a larger discovery/link-bank layer. This register prevents false completeness claims and controls research order.

Status meanings:

- **Verified seed**: at least one source-bound current route exists; it is not whole-domain coverage.
- **Source mapped**: authoritative entry points are identified, but route logic is not fully extracted/reviewed.
- **Research queue**: priority has been defined; no reusable claim should be made yet.
- **Live discovery only**: programmes/projects/opportunities require current provider verification for each candidate.

## Rule for future work

Do not say a domain is researched because a homepage or one article has been read. It reaches verified coverage only after route-level extraction, official citation, required fact set, authority boundary, review date and operator-facing next step are recorded.
