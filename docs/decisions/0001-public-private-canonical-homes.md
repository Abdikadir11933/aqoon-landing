# ADR 0001: Public/private canonical homes

Status: accepted.

Public GitHub is product code + public verified knowledge + AI routing. Private ops owns confidential strategy/sales/pilot raw evidence. Supabase/private systems own family records and interviews. Live research owns today's jobs, programmes, deadlines, prices, capacity and changed authority criteria.

Reason: prevent PII leakage, stale duplicated truths and agents loading irrelevant context.
