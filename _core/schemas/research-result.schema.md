# Research Result Schema

```yaml
match_status: confirmed-match | possible-must-confirm | does-not-fit
candidate_id:
matched_criteria: []
missing_criteria: []
conflicting_criteria: []
decision_maker:

verified_at:

```

`confirmed-match` means current published criteria appear to fit the known facts. It never means approved.
