# Localization Policy

## Somali public copy

Write for comprehension in Finland, not literal translation.

- Use short, direct sentences and everyday Standard Somali.
- Prefer direct second-person wording where natural.
- Keep familiar Finnish service/system names when users need to recognise the same term in real life: Kela, OmaKela, päiväkoti, esiopetus, Wilma, YKI, Työmarkkinatori, työllisyyspalvelut, palveluseteli, kotihoidon tuki, asumistuki, toimeentulotuki, palkkatuki, hygieniapassi, työturvallisuuskortti.
- At first mention, keep the Finnish name and explain it briefly in Somali.
- Do not paste whole Finnish sentences into Somali copy.
- Avoid unnecessary English bureaucratic words when Somali is clear: use `bogga rasmiga ah`, `linkiga rasmiga ah`, `taariikhda ugu dambeysa`, `shuruudaha`, `codsi`, `isdiiwaangelin`, `adeeg`, `taageero`.
- Keep official programme/product names unchanged.
- `TE-toimisto` is a legacy term. For current services normally use `työllisyyspalvelut` / employment area and explain the old term only when needed.

Quality target: clear Somali that sounds like a knowledgeable Somali-speaking person explaining the issue over WhatsApp, cleaned up for a professional public service.
