# Public / Private Boundary

## Public GitHub may contain
- product code
- public verified service knowledge
- schemas, QA rules and routing instructions
- official/provider source registries
- sanitized methodology and aggregated evidence

## Never place in public GitHub
- family names, phone numbers, email addresses or case notes
- interview transcripts tied to identifiable people
- private buyer messages or sales pipeline details
- confidential pilot material or commercial negotiations
- secrets, service-role keys, passwords or private tokens

## Canonical private homes
- family operational state and interviews: private Supabase / approved private systems
- confidential sales and pilot notes: private ops workspace
- public reusable knowledge: this repository

If material mixes public facts with private context, extract only the reusable sanitized fact and keep the raw source private.
